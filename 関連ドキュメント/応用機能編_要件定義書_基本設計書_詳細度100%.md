# 書籍レビューアプリ 要件定義書・基本設計書（応用機能編）

## 1. はじめに

### 1.1. 本書の目的

本書は、書籍レビューアプリケーションの「応用機能編」開発における要件と設計を定義するものである。基本機能編をベースに、より高度な機能と高品質なコードスタイルを導入することを目的とする。本書を読むことで、学習者は応用機能の全体像と技術的仕様を正確に把握し、手順書に従って実装を進めることができる。

### 1.2. 前提条件

- 基本機能編のすべての要件を満たしていること。
- 開発言語・フレームワークは PHP / Laravel (Laravel 10.x) を使用する。
- フロントエンドのBladeテンプレートは `coachtech-material/Preparedblade-mockcase-BookShelf` リポジトリの `advanced` ブランチで提供される。
- データベースは MySQL を使用する。
- 開発環境は Docker および Laravel Sail を使用する。

## 2. 環境構築手順

### 2.1. Laravelプロジェクトの作成 (Laravel 10.x)

以下のDockerコマンドを実行して、Laravel 10.xを明示的に指定してプロジェクトを作成します。

```bash
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    composer create-project laravel/laravel:^10.0 book-review-app
```

### 2.2. Laravel Sailのインストール

プロジェクト作成後、`book-review-app` ディレクトリに移動し、Laravel Sailをインストールします。

```bash
# プロジェクトディレクトリに移動
cd book-review-app

# Laravel Sailをインストール
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    composer require laravel/sail --dev

# Sailの設定ファイルをパブリッシュ（MySQLを選択）
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    php artisan sail:install --with=mysql
```

    新しいターミナルを開いて実行します。このコマンドは開発中、常に実行したままにしてください。

### 3.1. 高度な検索機能 - 詳細仕様

#### 3.1.1. 機能概要
書籍一覧ページで、複数の条件（キーワード、ジャンル、並び順）を組み合わせて書籍を検索する機能。

#### 3.1.2. 画面仕様
- 書籍一覧ページ (`/books`) の上部に検索フォームを設置する。
- 検索フォームには以下の項目が含まれる。
  - キーワード入力欄 (`text`)
  - ジャンル選択プルダウン (`select`)
  - 並び順選択プルダウン (`select`)
- 検索を実行すると、検索条件を維持したまま結果がページネーションで表示される。

#### 3.1.3. フォーム項目
| 項目名 | `name`属性 | 型 | 必須 |
|---|---|---|---|
| キーワード | `keyword` | `text` | |
| ジャンル | `genre` | `select` | |
| 並び順 | `sort` | `select` | |

#### 3.1.4. 検索条件
| 項目 | `name`属性 | 説明 |
|---|---|---|
| キーワード | `keyword` | 書籍の「タイトル」または「著者」に対して部分一致検索を行う。 |
| ジャンル | `genre` | 指定されたジャンルIDに紐付く書籍のみを絞り込む。 |
| 並び順 | `sort` | 以下のいずれかで結果をソートする。<br>- `latest`: 登録日が新しい順（デフォルト）<br>- `oldest`: 登録日が古い順<br>- `title`: タイトル昇順<br>- `rating`: レビューの平均評価点が高い順 |

#### 3.1.5. 並び順オプション
| 値 | 表示名 | 説明 |
|---|---|---|
| `latest` | 登録日が新しい順 | デフォルト。`created_at DESC` でソート。 |
| `oldest` | 登録日が古い順 | `created_at ASC` でソート。 |
| `title` | タイトル順 | `title ASC` でソート。 |
| `rating` | 評価が高い順 | `reviews_avg_rating DESC` でソート。レビューがない書籍は最後に表示。 |

### 3.2. CSVエクスポート機能 - 詳細仕様

#### 3.2.1. 機能概要
書籍一覧ページの検索結果をCSVファイルとしてダウンロードする機能。

#### 3.2.2. 画面遷移・動作
1. **[開始]** ユーザーが書籍一覧ページで「CSVエクスポート」ボタンをクリックする。
2. 現在の検索条件（キーワード、ジャンル）を引き継いで、該当する書籍データがCSVファイルとしてダウンロードされる。

#### 3.2.3. CSVファイル仕様
| 仕様項目 | 値 |
|---|---|
| ファイル名 | `books_YYYYMMDD_HHMMSS.csv` (例: `books_20260102_153000.csv`) |
| 文字コード | `UTF-8` (BOM付き) |
| ヘッダー行 | `ID`, `タイトル`, `著者`, `ISBN`, `出版日`, `ジャンル`, `登録日` |
| データ行 | - **ジャンル**: 複数の場合はカンマ区切りで出力 (例: `文学, SF`)<br>- **日付**: `YYYY-MM-DD` または `YYYY-MM-DD HH:MM:SS` 形式 |

#### 3.2.4. CSVヘッダー詳細
| カラム番号 | ヘッダー名 | データ元 |
|---|---|---|
| 1 | ID | `$book->id` |
| 2 | タイトル | `$book->title` |
| 3 | 著者 | `$book->author` |
| 4 | ISBN | `$book->isbn` |
| 5 | 出版日 | `$book->published_date` (YYYY-MM-DD形式) |
| 6 | ジャンル | `$book->genres->pluck('name')->implode(', ')` |
| 7 | 登録日 | `$book->created_at` (YYYY-MM-DD HH:MM:SS形式) |

### 3.3. ISBN書籍検索機能 - 詳細仕様

#### 3.3.1. 機能概要
書籍登録・編集ページで、ISBN-13コードを入力してGoogle Books APIから書籍情報を取得し、フォームに自動入力する機能。

#### 3.3.2. 画面仕様・動作
1. **[開始]** ユーザーが書籍登録・編集ページでISBN-13入力欄に13桁の数字を入力し、「検索」ボタンをクリックする。
2. JavaScriptがバックエンドのAPI (`/books/isbn/{isbn}`) にリクエストを送信する。
3. **[正常系]** APIから書籍情報が返却され、対応するフォーム項目（タイトル, 著者, 出版日, 概要, 画像URL）に自動で値が設定される。
4. **[異常系]** APIからエラーが返却された場合、アラートでエラーメッセージを表示する。

#### 3.3.3. API仕様 (バックエンド)
- **エンドポイント**: `/books/isbn/{isbn}`
- **HTTPメソッド**: `GET`
- **URLパラメータ**: `isbn` (13桁の文字列)
- **レスポンス (成功時)**: `200 OK`
  ```json
  {
    "title": "パーフェクトPHP",
    "author": "小川 雄大",
    "published_date": "2021-10-19",
    "description": "...",
    "image_url": "..."
  }
  ```
- **レスポンス (バリデーションエラー)**: `400 Bad Request`
  ```json
  {"error": "ISBNは13桁で入力してください。"}
  ```
- **レスポンス (書籍見つからず)**: `404 Not Found`
  ```json
  {"error": "書籍が見つかりませんでした。"}
  ```
- **レスポンス (API通信エラー)**: `500 Internal Server Error`
  ```json
  {"error": "API通信エラーが発生しました。"}
  ```

#### 3.3.4. フォーム自動入力マッピング
| Google Books APIフィールド | フォーム項目 (`name`属性) |
|---|---|
| `volumeInfo.title` | `title` |
| `volumeInfo.authors[0]` | `author` |
| `volumeInfo.publishedDate` | `published_date` |
| `volumeInfo.description` | `description` |
| `volumeInfo.imageLinks.thumbnail` | `image_url` |

### 3.4. マイ読書レポート機能 - 詳細仕様

#### 3.4.1. 機能概要
ログインユーザー自身の読書活動に関する様々な統計情報を表示する機能。

#### 3.4.2. 画面仕様
- **URL**: `/reports`
- 以下の統計情報が表示される。

| 統計項目 | 説明 | 難易度 |
|---|---|---|
| 基本サマリー | 総レビュー数、読了冊数（ユニーク書籍数）、平均評価点の3つの数値を表示する。 | ★★☆ |
| 評価分布 | ユーザーが投稿したレビューの評価（1〜5星）ごとの件数を横バーで表示する。 | ★★★ |
| 高評価書籍TOP5 | ユーザーが4星以上の評価をつけた書籍を、評価の高い順に最大5件リスト形式で表示する。書籍詳細ページへのリンクを含む。 | ★★★ |
| ジャンル別評価傾向TOP5 | ユーザーがどのジャンルを高く評価する傾向があるかを、平均評価の高い順に最大5件表示する。各ジャンルのレビュー数と平均評価を含む。ジャンル別書籍一覧ページへのリンクを含む。 | ★★★★ |

#### 3.4.3. 算出ロジック
| 統計項目 | 算出ロジック |
|---|---|
| 総レビュー数 | `$reviews->count()` |
| 読了冊数 | `$reviews->pluck('book_id')->unique()->count()` |
| 平均評価点 | `$reviews->avg('rating')` |
| 評価分布 | `$reviews->groupBy('rating')` で評価ごとにグループ化し、`map()` で各グループの件数を算出。存在しない評価は0件として補完する。 |
| 高評価書籍TOP5 | `$reviews->filter(fn ($r) => $r->rating >= 4)->sortByDesc('rating')->take(5)->map(fn ($r) => [...])` で4星以上の書籍を評価の高い順に抽出。 |
| ジャンル別評価傾向TOP5 | `$reviews->flatMap(...)` で多対多リレーション（Book ↔ Genre）を展開し、`groupBy('genre_id')->map(...)` でジャンルごとに平均評価と件数を集計。`sortByDesc('average_rating')->take(5)` で上位5件を抽出。 |

#### 3.4.4. 表示形式
- **基本サマリー**: 3つの数値をカード形式で横並びに表示する。
- **評価分布**: 1〜5星の5本の横バーを表示する。レビューがない評価は0件として表示する。
- **高評価書籍TOP5**: 書籍タイトル、著者、評価を含むリストを最大5件表示する。各項目は書籍詳細ページへのリンクとなる。4星以上のレビューがない場合は「4星以上の書籍がありません」と表示する。
- **ジャンル別評価傾向TOP5**: ジャンル名、レビュー数、平均評価を含むリストを最大5件表示する。各項目はジャンル別書籍一覧ページ（`genres.show`）へのリンクとなる。ジャンルが設定された書籍のレビューがない場合は「ジャンルが設定された書籍のレビューがありません」と表示する。

### 3.5. 公開API機能 - 詳細仕様

#### 3.5.1. 機能概要
外部アプリケーション向けに、書籍の一覧と詳細情報をJSON形式で提供する認証不要のAPI。

#### 3.5.2. エンドポイント一覧
| HTTPメソッド | URI | 説明 |
|---|---|---|
| GET | `/api/v1/books` | 書籍一覧を取得する。 |
| GET | `/api/v1/books/{book}` | 書籍詳細を取得する。 |

#### 3.5.3. 書籍一覧API (`GET /api/v1/books`)

##### リクエストパラメータ
| パラメータ | 型 | 必須 | 説明 |
|---|---|---|---|
| `keyword` | string | | タイトル・著者での部分一致検索 |
| `genre_id` | integer | | ジャンルIDでの絞り込み |
| `page` | integer | | ページ番号（デフォルト: 1） |
| `per_page` | integer | | 1ページあたりの件数（デフォルト: 20、最大: 100） |

##### レスポンス (成功時): `200 OK`
```json
{
  "data": [
    {
      "id": 1,
      "title": "パーフェクトPHP",
      "author": "小川 雄大",
      "isbn": "9784297124219",
      "published_date": "2021-10-19",
      "genres": [
        {"id": 1, "name": "技術書"}
      ],
      "average_rating": 4.5,
      "review_count": 10
    }
  ],
  "meta": {
    "current_page": 1,
    "last_page": 5,
    "per_page": 20,
    "total": 100
  }
}
```

## 4. 非機能要件（追加・変更分）

| 項目 | 要件 |
|---|---|
| **コーディングスタイル** | - **型宣言の徹底**: すべてのコントローラ、モデル、FormRequest、Policyのメソッドに、引数と戻り値の型を明示的に宣言する。（例: `public function index(): View`）<br>- **リレーション戻り値型**: モデルのリレーションメソッドには、`HasMany`, `BelongsTo` などの具体的な戻り値型を宣言する。<br>- **PHPDoc**: 主要なメソッドには、処理内容、引数、戻り値を説明するPHPDocコメントを記述する。 |
| **Collectionメソッド** | - **宣言的なコード**: `foreach` などの手続き的なループを避け、`map`, `filter`, `groupBy`, `flatMap` などのCollectionメソッドを積極的に活用し、宣言的で可読性の高いコードを記述する。特にマイ読書レポート機能でこれを徹底する。 |
| **外部連携** | - **HTTPクライアント**: 外部APIとの通信には、Laravel標準のHTTPクライアント (`Illuminate\Support\Facades\Http`) を使用する。 |
| **ファイルダウンロード** | - **ストリーミング**: CSVエクスポートなどの大容量ファイルを扱う可能性がある機能では、メモリ消費を抑えるため `StreamedResponse` を使用してレスポンスをストリーミングする。 |

### 5.2. コントローラ設計

| コントローラ | メソッド | 詳細仕様 |
|---|---|---|
| **BookController** | `index` | **検索機能**: `Builder::when()` を使用して、リクエストに存在するパラメータ（`keyword`, `genre_id`, `sort`）に応じて動的にクエリを構築する。<br>- `keyword`: `title` と `author` カラムに対して `LIKE`検索を行う。<br>- `genre_id`: `whereHas('genres', ...)` でジャンルによる絞り込みを行う。<br>- `sort`: `orderBy()` で並び替えを行う。`rating` の場合は `withAvg` と `orderByDesc('reviews_avg_rating')` を使用する。 |
| | `csvExport` | **CSVエクスポート**: `StreamedResponse` を使用する。<br>1. HTTPヘッダ（`Content-Type`, `Content-Disposition`）を設定。<br>2. `fopen('php://output', 'w')` で出力ストリームを開く。<br>3. `fputcsv()` でヘッダ行を書き込む。<br>4. `Book::query()->cursor()` を使用して、メモリ消費を抑えながら1件ずつ書籍データを取得し、`fputcsv()` で書き込む。 |
| | `searchByIsbn` | **ISBN検索**: `Http::get()` でGoogle Books API (`https://www.googleapis.com/books/v1/volumes`) を叩く。<br>1. `q` パラメータに `isbn:{isbn}` を指定。<br>2. `key` パラメータに `.env` から取得したAPIキーを指定。<br>3. 成功時 (`successful()` かつ `totalItems > 0`)、最初の書籍情報 (`items[0].volumeInfo`) をJSONで返す。<br>4. 失敗時は空のJSON (`{}`) を返す。 |
| **ReportController** | `index` | **マイ読書レポート**: Collectionメソッドを駆使して各種統計を算出する。<br>1. **データ取得**: `Auth::user()->reviews()->with('book.genres')->get()` でユーザーの全レビューを取得。<br>2. **基本サマリー**: `count()`, `pluck('book_id')->unique()->count()`, `avg('rating')` で総レビュー数・読了冊数・平均評価を算出。<br>3. **評価分布**: `groupBy('rating')` で評価ごとにグループ化し、`map()` で各グループの件数を算出。存在しない評価は0で補完。<br>4. **高評価書籍TOP5**: `filter(fn ($r) => $r->rating >= 4)->sortByDesc('rating')->take(5)->map(...)` で4星以上の書籍情報を抽出。<br>5. **ジャンル別評価傾向TOP5**: `flatMap()` で多対多リレーションを展開し、`groupBy('genre_id')->map(...)->sortByDesc('average_rating')->take(5)` でジャンル別統計を算出。 |
| **Api\V1\BookController** | `index` | `Book::query()` を使用し、リクエストパラメータ (`keyword`, `genre_id`) に応じて検索を行う。`paginate(20)` で結果を返す。 |
| | `show` | `load(["reviews.user", "genres"])` で関連情報をロードし、JSONで返す。 |

### 5.4. Collectionメソッド活用設計

`ReportController` の `index` メソッドは、以下のCollectionメソッドを組み合わせて実装することを必須要件とする。

| メソッド | 目的 | 使用箇所 |
|---|---|---|
| `count()` | コレクションの要素数を取得する。 | 総レビュー数、各グループの件数算出 |
| `pluck()` | 特定のキーの値のコレクションを取得する。 | 読了冊数（book_id抽出） |
| `unique()` | 重複を除外する。 | 読了冊数（ユニーク書籍数） |
| `avg()` | 平均値を算出する。 | 平均評価点の算出、ジャンル別平均評価 |
| `groupBy()` | 指定したキーでコレクションをグループ化する。 | 評価分布、ジャンル別評価傾向 |
| `map()` | コレクションの各要素にコールバックを適用する。 | 評価分布の件数算出、高評価書籍の整形、ジャンル別集計 |
| `filter()` | 条件に合う要素のみ抽出する。 | 高評価書籍（4星以上） |
| `sortByDesc()` | コレクションを降順でソートする。 | 高評価書籍、ジャンル別評価傾向 |
| `take()` | 先頭からN件を取得する。 | TOP5の抽出 |
| `values()` | コレクションのキーを連番に振り直す。 | 高評価書籍TOP5、ジャンル別TOP5の整形 |
| `flatMap()` | 各要素を複数要素に展開し平坦化する（応用）。 | ジャンル別評価傾向（多対多リレーションの展開） |
