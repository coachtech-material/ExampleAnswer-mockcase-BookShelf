# 書籍レビューアプリ 要件定義書（基本機能編）- 超詳細版

## 1. 書籍管理機能

### 1.1. 書籍登録機能

#### 1.1.1. 機能概要
ユーザーが新しい書籍の情報をシステムに登録する機能。

#### 1.1.2. 画面遷移
1.  **[開始]** ユーザーがヘッダーの「書籍登録」リンクをクリックする。
2.  書籍登録画面 (`/books/create`) に遷移する。
3.  ユーザーが必要事項を入力し、「登録」ボタンをクリックする。
4.  **[正常系]** 書籍がデータベースに保存され、登録した書籍の詳細画面 (`/books/{book_id}`) にリダイレクトされる。画面上部に「書籍を登録しました。」というフラッシュメッセージが表示される。
5.  **[異常系]** バリデーションエラーが発生した場合、書籍登録画面 (`/books/create`) にリダイレクトされる。入力内容は維持され、各項目の下にエラーメッセージが表示される。

#### 1.1.3. フォーム項目
| 項目名 | `name`属性 | 型 | 必須 |
|---|---|---|---|
| タイトル | `title` | `text` | ✔ |
| 著者 | `author` | `text` | ✔ |
| ISBN-13 | `isbn` | `text` | ✔ |
| 出版日 | `published_date` | `date` | ✔ |
| 概要 | `description` | `textarea` | |
| 画像URL | `image_url` | `url` | |
| ジャンル | `genres[]` | `checkbox` | ✔ |

#### 1.1.4. バリデーションルール
| 項目名 | ルール | エラーメッセージ（例） |
|---|---|---|
| タイトル | `required` | 「タイトルは必須です。」 |
| | `string` | 「タイトルは文字列で入力してください。」 |
| | `max:255` | 「タイトルは255文字以内で入力してください。」 |
| 著者 | `required` | 「著者名は必須です。」 |
| | `string` | 「著者名は文字列で入力してください。」 |
| | `max:255` | 「著者名は255文字以内で入力してください。」 |
| ISBN-13 | `required` | 「ISBNは必須です。」 |
| | `string` | 「ISBNは文字列で入力してください。」 |
| | `size:13` | 「ISBNは13桁で入力してください。」 |
| | `unique:books,isbn` | 「そのISBNは既に使用されています。」 |
| 出版日 | `required` | 「出版日は必須です。」 |
| | `date` | 「出版日は有効な日付形式で入力してください。」 |
| 概要 | `nullable` | - |
| | `string` | 「概要は文字列で入力してください。」 |
| 画像URL | `nullable` | - |
| | `url` | 「画像URLは有効なURL形式で入力してください。」 |
| ジャンル | `required` | 「ジャンルは1つ以上選択してください。」 |
| | `array` | 「ジャンルは配列で入力してください。」 |
| ジャンル.* | `exists:genres,id` | 「選択されたジャンルは存在しません。」 |

### 1.2. 書籍編集機能

#### 1.2.1. 機能概要
ユーザーが自身で登録した書籍の情報を編集する機能。

#### 1.2.2. 画面遷移
1.  **[開始]** ユーザーが自身で登録した書籍の詳細画面で「編集」ボタンをクリックする。
2.  書籍編集画面 (`/books/{book}/edit`) に遷移する。フォームには既存の情報が入力されている。
3.  ユーザーが必要事項を修正し、「更新」ボタンをクリックする。
4.  **[正常系]** 書籍情報がデータベースで更新され、編集した書籍の詳細画面 (`/books/{book_id}`) にリダイレクトされる。画面上部に「書籍情報を更新しました。」というフラッシュメッセージが表示される。
5.  **[異常系]** バリデーションエラーが発生した場合、書籍編集画面 (`/books/{book}/edit`) にリダイレクトされる。入力内容は維持され、各項目の下にエラーメッセージが表示される。
6.  **[認可エラー]** 他のユーザーが登録した書籍の編集ページにアクセスしようとすると、403 Forbiddenエラーページが表示される。

#### 1.2.3. バリデーションルール（更新時）
| 項目名 | ルール | エラーメッセージ（例） |
|---|---|---|
| ISBN-13 | `Rule::unique('books')->ignore($this->book)` | 「そのISBNは既に使用されています。」 |

※ その他の項目は登録時と同様。

### 1.3. 書籍削除機能

#### 1.3.1. 機能概要
ユーザーが自身で登録した書籍を削除する機能。

#### 1.3.2. 画面遷移
1.  **[開始]** ユーザーが自身で登録した書籍の詳細画面で「削除」ボタンをクリックする。
2.  確認ダイアログが表示され、「OK」をクリックする。
3.  **[正常系]** 書籍がデータベースから削除され、書籍一覧画面 (`/books`) にリダイレクトされる。画面上部に「書籍を削除しました。」というフラッシュメッセージが表示される。
4.  **[認可エラー]** 他のユーザーが登録した書籍を削除しようとすると、403 Forbiddenエラーページが表示される。

## 2. レビュー管理機能

### 2.1. レビュー投稿機能

#### 2.1.1. 機能概要
書籍詳細ページから、その書籍に対するレビュー（5段階評価・コメント）を投稿する機能。

#### 2.1.2. 画面遷移
1.  **[開始]** ユーザーが書籍詳細ページで評価とコメントを入力し、「レビューを投稿」ボタンをクリックする。
2.  **[正常系]** レビューがデータベースに保存され、同じ書籍詳細画面 (`/books/{book_id}`) にリダイレクトされる。画面上部に「レビューを投稿しました。」というフラッシュメッセージが表示される。
3.  **[異常系]** バリデーションエラーが発生した場合、同じ書籍詳細画面 (`/books/{book_id}`) にリダイレクトされる。入力内容は維持され、フォームの下にエラーメッセージが表示される。

#### 2.1.3. フォーム項目
| 項目名 | `name`属性 | 型 | 必須 |
|---|---|---|---|
| 評価 | `rating` | `select` (1-5) | ✔ |
| コメント | `comment` | `textarea` | |

#### 2.1.4. バリデーションルール
| 項目名 | ルール | エラーメッセージ（例） |
|---|---|---|
| 評価 | `required` | 「評価は必須です。」 |
| | `integer` | 「評価は整数で入力してください。」 |
| | `min:1` | 「評価は1以上で入力してください。」 |
| | `max:5` | 「評価は5以下で入力してください。」 |
| コメント | `nullable` | - |
| | `string` | 「コメントは文字列で入力してください。」 |
| | `max:1000` | 「コメントは1000文字以内で入力してください。」 |

## 3. ジャンル管理機能

### 3.1. ジャンル登録機能

#### 3.1.1. 機能概要
管理者が新しいジャンルを登録する機能。

#### 3.1.2. 画面遷移
1.  **[開始]** ジャンル管理画面 (`/genres`) で「新規登録」ボタンをクリックする。
2.  ジャンル登録画面 (`/genres/create`) に遷移する。
3.  ジャンル名を入力し、「登録」ボタンをクリックする。
4.  **[正常系]** ジャンルがデータベースに保存され、ジャンル管理画面 (`/genres`) にリダイレクトされる。画面上部に「ジャンルを作成しました。」というフラッシュメッセージが表示される。
5.  **[異常系]** バリデーションエラーが発生した場合、ジャンル登録画面 (`/genres/create`) にリダイレクトされる。入力内容は維持され、項目の下にエラーメッセージが表示される。

#### 3.1.3. バリデーションルール
| 項目名 | ルール | エラーメッセージ（例） |
|---|---|---|
| ジャンル名 | `required` | 「ジャンル名は必須です。」 |
| | `string` | 「ジャンル名は文字列で入力してください。」 |
| | `max:255` | 「ジャンル名は255文字以内で入力してください。」 |
| | `unique:genres,name` | 「そのジャンル名は既に使用されています。」 |

### 3.2. ジャンル削除機能

#### 3.2.1. 機能概要
管理者が既存のジャンルを削除する機能。ただし、そのジャンルに紐付く書籍が存在しない場合に限る。

#### 3.2.2. 画面遷移
1.  **[開始]** ユーザーがジャンル管理画面で「削除」ボタンをクリックする。
2.  **[正常系]** 紐付く書籍がない場合、ジャンルがデータベースから削除され、ジャンル管理画面 (`/genres`) にリダイレクトされる。画面上部に「ジャンルを削除しました。」というフラッシュメッセージが表示される。
3.  **[異常系]** 紐付く書籍が存在する場合、処理は中断され、ジャンル管理画面 (`/genres`) にリダイレクトされる。画面上部に「このジャンルには書籍が紐付いているため削除できません。」というエラーメッセージが表示される。
