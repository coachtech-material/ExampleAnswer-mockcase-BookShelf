# 書籍レビューアプリ 採点項目（基本機能編）

| 大項目 | 満点 | 得点 |
|---|---|---|
| A. プロジェクト設定とドキュメント | 15点 | |
| B. データベース設計と実装 | 20点 | |
| C. 機能実装 | 45点 | |
| D. コード品質（非機能要件） | 15点 | |
| E. Git利用 | 5点 | |
| **合計** | **100点** | |

---

### A. プロジェクト設定とドキュメント (15点)

| No. | 採点項目 | 配点 | チェック |
|---|---|---|---|
| A-1 | `README.md` が作成され、プロジェクト概要、機能一覧、使用技術、**環境構築手順**が分かりやすく記載されているか。 | 5点 | |
| A-2 | `README.md` に記載の手順通りに、エラーなく環境構築（`sail up`, `migrate`, `db:seed` 等）が完了できるか。 | 5点 | |
| A-3 | `.env.example` が適切に準備されており、環境変数の設定漏れがないか。 | 5点 | |

### B. データベース設計と実装 (20点)

| No. | 採点項目 | 配点 | チェック |
|---|---|---|---|
| B-1 | ER図が要件定義書通りに作成されており、テーブルとリレーションシップが正確に表現されているか。 | 5点 | |
| B-2 | マイグレーションファイルが適切に作成されており、`sail artisan migrate` で全テーブルが正常に作成されるか。 | 5点 | |
| B-3 | 各モデル（`User`, `Book`, `Review` 等）でリレーションシップ（`hasMany`, `belongsTo`, `belongsToMany`）が正しく定義されているか。 | 5点 | |
| B-4 | Seederが作成されており、`sail artisan db:seed` で開発に必要なダミーデータ（ユーザー、書籍、レビュー等）が作成されるか。 | 5点 | |

### C. 機能実装 (45点)

| No. | 採点項目 | 配点 | チェック |
|---|---|---|---|
| C-1 | **認証**: ユーザー登録、ログイン、ログアウト機能が正常に動作するか。 | 5点 | |
| C-2 | **書籍CRUD**: 書籍の一覧、詳細、登録、編集、削除が要件通りに動作するか。 | 10点 | |
| C-3 | **レビューCRUD**: レビューの投稿、編集、削除が要件通りに動作するか。 | 10点 | |
| C-4 | **お気に入り機能**: お気に入りの登録・解除、一覧表示が正常に動作するか。 | 5点 | |
| C-5 | **いいね機能**: レビューへの「いいね」の登録・解除が正常に動作するか。 | 5点 | |
| C-6 | **ジャンル管理機能**: ジャンルのCRUD、ジャンル別書籍一覧が正常に動作するか。 | 5点 | |
| C-7 | **ランキング機能**: レビューの平均評価に基づいた書籍ランキングが正しく表示されるか。 | 5点 | |

### D. コード品質（非機能要件） (15点)

| No. | 採点項目 | 配点 | チェック |
|---|---|---|---|
| D-1 | **N+1問題の防止**: `with()` を使用したEager Loadingが適切に行われ、非効率なクエリが発行されていないか。 | 5点 | |
| D-2 | **認可処理**: `Policy` を使用して、他人の書籍やレビューを編集・削除できないように正しく制御されているか。 | 5点 | |
| D-3 | **バリデーション**: `FormRequest` を使用して、リクエストのバリデーションがコントローラから分離され、適切なルールが設定されているか。 | 5点 | |

### E. Git利用 (5点)

| No. | 採点項目 | 配点 | チェック |
|---|---|---|---|
| E-1 | コミットの粒度が適切か（1コミット1機能など）。メッセージは変更内容が分かりやすいように記述されているか（例: `feat: Add book review feature`）。 | 5点 | |
