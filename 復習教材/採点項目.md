### F. 応用機能実装 (35点)

| No. | 機能 | 採点項目 | 配点 | チェック |
|---|---|---|---|---|
| F-1 | **高度な検索** | キーワード（タイトル・著者）での検索が動作するか。 | 3点 | |
| F-2 | | ジャンルでの絞り込みが動作するか。 | 3点 | |
| F-3 | | 並び順（登録日、評価）の変更が動作するか。 | 4点 | |
| F-4 | **CSVエクスポート** | 検索結果をCSV形式でダウンロードできるか。 | 5点 | |
| F-5 | | 大容量データでもメモリを圧迫しないようにストリーミングされているか。 | 5点 | |

| F-7 | **マイ読書レポート** | 読書統計（総読了冊数、レビュー投稿日数、読書継続日数、月別統計）が正しく計算・表示されるか。 | 5点 | |
