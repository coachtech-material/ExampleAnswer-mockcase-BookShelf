# 書籍レビューアプリ（基本機能編）要件定義書・基本設計書

## 1. はじめに

### 1.1. 本書の目的

本書は、Webアプリケーション「書籍レビューアプリ（基本機能編）」の開発における要件と基本設計を定義するものである。本書の記述に従い実装することで、`coachtech-material/ExampleAnswer-mockcase-BookShelf`リポジトリの`basic`ブランチと完全に一致する成果物が完成することを保証する。

### 1.2. 前提条件

- 開発言語・フレームワークは PHP / Laravel (Laravel 10.x) を使用する。
- フロントエンドのBladeテンプレートは `coachtech-material/Preparedblade-mockcase-BookShelf` リポジトリの `basic` ブランチで提供される。
- データベースは MySQL を使用する。

## 2. 環境構築手順

### 2.1. Laravelプロジェクトの作成 (Laravel 10.x)

以下のDockerコマンドを実行して、Laravel 10.xを明示的に指定してプロジェクトを作成します。

```bash
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    composer create-project laravel/laravel:^10.0 book-review-app
```

### 2.2. Laravel Sailのインストール

プロジェクト作成後、`book-review-app` ディレクトリに移動し、Laravel Sailをインストールします。

```bash
# プロジェクトディレクトリに移動
cd book-review-app

# Laravel Sailをインストール
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    composer require laravel/sail --dev

# Sailの設定ファイルをパブリッシュ（MySQLを選択）
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    php artisan sail:install --with=mysql
```

### 2.3. フロントエンドのセットアップ (Vite & Tailwind CSS)

1.  **NPM依存パッケージのインストール**
    ```bash
    sail npm install
    ```

2.  **Tailwind CSSのインストール**
    ```bash
    sail npm install -D tailwindcss@^3.4.0 postcss autoprefixer
    ```

3.  **設定ファイルの生成**
    ```bash
    sail npx tailwindcss init -p
    ```

4.  **Tailwind CSSのテンプレートパス設定**
    `tailwind.config.js` を開き、`content`プロパティを以下のように設定します。
    ```javascript
    /** @type {import('tailwindcss').Config} */
    export default {
      content: [
        "./resources/**/*.blade.php",
        "./resources/**/*.js",
        "./resources/**/*.vue",
      ],
      theme: {
        extend: {},
      },
      plugins: [],
    }
    ```

5.  **CSSファイルにTailwindディレクティブを追加**
    `resources/css/app.css` の中身を以下の3行に置き換えます。
    ```css
    @tailwind base;
    @tailwind components;
    @tailwind utilities;
    ```

6.  **Vite開発サーバーの起動**
    新しいターミナルを開いて実行します。このコマンドは開発中、常に実行したままにしてください。
    ```bash
    sail npm run dev
    ```

### 2.4. .env ファイルとphpMyAdminの設定

1.  **.env ファイルの確認**
    `.env` ファイルを開き、データベース接続情報が以下と一致していることを確認します。
    ```ini
    DB_CONNECTION=mysql
    DB_HOST=mysql
    DB_PORT=3306
    DB_DATABASE=laravel
    DB_USERNAME=sail
    DB_PASSWORD=password
    ```

2.  **phpMyAdminの追加**
    `compose.yaml` を開き、`mysql` サービスの後に以下の設定を追加します。
    ```yaml
        phpmyadmin:
            image: 'phpmyadmin:latest'
            ports:
                - '${FORWARD_PHPMYADMIN_PORT:-8080}:80'
            environment:
                PMA_HOST: mysql
                PMA_USER: '${DB_USERNAME}'
                PMA_PASSWORD: '${DB_PASSWORD}'
            networks:
                - sail
            depends_on:
                - mysql
    ```

### 2.5. Sailの起動とエイリアス設定

1.  **Sailの起動**
    ```bash
    ./vendor/bin/sail up -d
    ```

2.  **エイリアス設定**
    ```bash
    echo "alias sail='[ -f sail ] && bash sail || bash vendor/bin/sail'" >> ~/.zshrc
    # または bash の場合
    # echo "alias sail='[ -f sail ] && bash sail || bash vendor/bin/sail'" >> ~/.bashrc
    
    # シェルを再起動
    exec $SHELL
    ```

3.  **アプリケーションキーの生成**
    ```bash
    sail artisan key:generate
    ```

### 2.6. 模範解答リポジトリの適用

ここまでの手順で作成したLaravelプロジェクトに、模範解答のコードを適用します。

1.  **模範解答リポジトリのクローン**

2.  **Bladeテンプレートのクローン**

3.  **ファイルのコピー**

    - `bookshelf_blade` の `resources/views` ディレクトリ

ここまでで、マイグレーションを実行する前の環境構築が完了します。

## 3. 機能要件

| 大項目 | 機能 | 概要 |
|---|---|---|
| ユーザー認証 | 会員登録 | メールアドレス、パスワードでユーザー登録ができる。 |
| | ログイン・ログアウト | 登録した情報でログイン・ログアウトができる。 |
| | プロフィール編集 | ユーザー名、メールアドレスを変更できる。 |
| 書籍管理 | 書籍一覧表示 | 登録されている書籍を最新順に10件ずつページネーションで表示する。 |
| | 書籍詳細表示 | 書籍のタイトル、著者、画像、説明、ジャンル、およびその書籍に投稿されたレビュー一覧を表示する。 |
| | 書籍登録 | 書籍のタイトル、著者、ISBN、出版日、説明、画像URL、ジャンルを登録できる。 |
| | 書籍編集 | 自身が登録した書籍の情報を編集できる。 |
| | 書籍削除 | 自身が登録した書籍を削除できる。 |
| レビュー管理 | レビュー投稿 | 書籍詳細ページから、5段階評価とコメントでレビューを投稿できる。 |
| | レビュー編集 | 自身が投稿したレビューを編集できる。 |
| | レビュー削除 | 自身が投稿したレビューを削除できる。 |
| お気に入り機能 | お気に入り登録・解除 | 書籍をお気に入りに登録、または解除できる。1つのボタンでトグル動作する。 |
| | お気に入り一覧 | 自身がお気に入りに登録した書籍を一覧で確認できる。 |
| いいね機能 | いいね登録・解除 | 他のユーザーのレビューに「いいね」を登録、または解除できる。1つのボタンでトグル動作する。 |
| ジャンル管理 | ジャンル一覧表示 | 登録されているジャンルを一覧で表示する。各ジャンルに紐づく書籍数も表示する。 |
| | ジャンル別書籍一覧 | 特定のジャンルに紐づく書籍を一覧で表示する。 |
| | ジャンル登録・編集・削除 | 新しいジャンルを登録、既存のジャンル名を編集、不要なジャンルを削除できる。書籍が紐づくジャンルは削除できない。 |
| ランキング機能 | 書籍ランキング表示 | レビューの平均評価が高い順に上位10件の書籍をランキング形式で表示する。 |

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| コーディングスタイル | ・Laravelの標準的なコーディング規約に従う。<br>・型宣言は行わないシンプルな実装とする。 |
| セキュリティ | ・CSRF対策をすべてのPOST/PUT/DELETEリクエストに適用する。<br>・認可（Policy）を実装し、他人の書籍やレビューを編集・削除できないようにする。 |
| パフォーマンス | ・書籍一覧、詳細表示でN+1問題が発生しないよう、`with()`や`load()`でEager Loadingを適切に行う。 |

### 5.3. コントローラ設計

| コントローラ | メソッド | 処理概要 |
|---|---|---|
| `BookController` | `index` | 書籍を10件ページネーションで取得し、`books.index`ビューを返す。 |
| | `create` | 全ジャンルを取得し、`books.create`ビューを返す。 |
| | `store` | `StoreBookRequest`でバリデーション後、書籍とジャンルの関連を保存。`books.show`へリダイレクト。 |
| | `show` | 書籍に関連するレビュー、いいね、ジャンルをEager Loadし、`books.show`ビューを返す。 |
| | `edit` | `BookPolicy`で認可後、書籍と全ジャンルを取得し、`books.edit`ビューを返す。 |
| | `update` | `BookPolicy`で認可後、`UpdateBookRequest`でバリデーションし、書籍とジャンルを更新。`books.show`へリダイレクト。 |
| | `destroy` | `BookPolicy`で認可後、書籍を削除。`books.index`へリダイレクト。 |
| `ReviewController` | `store` | `StoreReviewRequest`でバリデーション後、レビューを保存。`books.show`へリダイレクト。 |
| | `edit` | `ReviewPolicy`で認可後、`reviews.edit`ビューを返す。 |
| | `update` | `ReviewPolicy`で認可後、`UpdateReviewRequest`でバリデーションし、レビューを更新。`books.show`へリダイレクト。 |
| | `destroy` | `ReviewPolicy`で認可後、レビューを削除。`books.show`へリダイレクト。 |
| `FavoriteController` | `index` | ログインユーザーのお気に入り書籍を10件ページネーションで取得し、`favorites.index`ビューを返す。 |
| | `toggle` | ログインユーザーのお気に入り状態をトグル（登録/解除）する。元のページへリダイレクト。 |
| `ReviewLikeController` | `toggle` | ログインユーザーのレビューいいね状態をトグル（登録/解除）する。元のページへリダイレクト。 |
| `GenreController` | `index` | 全ジャンルを書籍数と共に取得し、`genres.index`ビューを返す。 |
| | `create` | `genres.create`ビューを返す。 |
| | `store` | `StoreGenreRequest`でバリデーション後、ジャンルを保存。`genres.index`へリダイレクト。 |
| | `show` | 特定ジャンルに紐づく書籍を10件ページネーションで取得し、`genres.show`ビューを返す。 |
| | `edit` | `genres.edit`ビューを返す。 |
| | `update` | `UpdateGenreRequest`でバリデーション後、ジャンルを更新。`genres.index`へリダイレクト。 |
| | `destroy` | 紐づく書籍がないことを確認後、ジャンルを削除。`genres.index`へリダイレクト。 |
| `RankingController` | `index` | レビューの平均評価とレビュー数で書籍をグループ化し、平均評価の高い順に10件取得。`ranking.index`ビューを返す。 |

### 5.4. バリデーション設計 (FormRequest)

| FormRequest | フィールド | ルール |
|---|---|---|
| `StoreBookRequest` | `title` | `required`, `string`, `max:255` |
| | `author` | `required`, `string`, `max:255` |
| | `isbn` | `required`, `string`, `size:13`, `unique:books,isbn` |
| | `published_date` | `required`, `date` |
| | `description` | `nullable`, `string` |
| | `image_url` | `nullable`, `url` |
| | `genres` | `required`, `array` |
| | `genres.*` | `exists:genres,id` |
| `UpdateBookRequest` | `isbn` | `required`, `string`, `size:13`, `Rule::unique('books')->ignore($this->book)` |
| | (その他) | `StoreBookRequest`に準ずる |
| `StoreReviewRequest` | `rating` | `required`, `integer`, `min:1`, `max:5` |
| | `comment` | `required`, `string`, `max:1000` |
| `UpdateReviewRequest` | (同上) | (同上) |
| `StoreGenreRequest` | `name` | `required`, `string`, `max:255`, `unique:genres,name` |
| `UpdateGenreRequest` | `name` | `required`, `string`, `max:255`, `Rule::unique('genres')->ignore($this->genre)` |

### 5.5. 認可設計 (Policy)

| Policy | メソッド | 認可ロジック |
|---|---|---|
| `BookPolicy` | `update` | `return $user->id === $book->user_id;` |
| | `delete` | `return $user->id === $book->user_id;` |
| `ReviewPolicy` | `update` | `return $user->id === $review->user_id;` |
| | `delete` | `return $user->id === $review->user_id;` |
