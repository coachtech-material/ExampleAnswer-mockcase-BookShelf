# 書籍レビューアプリ（応用機能編）要件定義書・基本設計書

## 1. はじめに

### 1.1. 本書の目的

本書は、Webアプリケーション「書籍レビューアプリ（応用機能編）」の開発における要件と基本設計を定義するものである。本書の記述に従い実装することで、`coachtech-material/ExampleAnswer-mockcase-BookShelf`リポジトリの`advanced`ブランチと完全に一致する成果物が完成することを保証する。

### 1.2. 前提条件

- **基本機能編のすべての機能が実装済み**であることを前提とする。
- 開発言語・フレームワークは PHP / Laravel (Laravel 10.x) を使用する。
- フロントエンドのBladeテンプレートは `coachtech-material/Preparedblade-mockcase-BookShelf` リポジトリの `advanced` ブランチで提供される。
- データベースは MySQL を使用する。

## 2. 環境構築手順

1.  **リポジトリのクローン**
    ```bash
    git clone https://github.com/coachtech-material/ExampleAnswer-mockcase-BookShelf.git bookshelf
    cd bookshelf
    git checkout advanced
    ```

2.  **Bladeテンプレートのクローン**
    ```bash
    git clone https://github.com/coachtech-material/Preparedblade-mockcase-BookShelf.git ../bookshelf-blade
    cp -r ../bookshelf-blade/resources/views/* ./resources/views/
    ```

3.  **環境設定**
    ```bash
    cp .env.example .env
    ```
    `.env`ファイルを開き、以下を設定する。
    - データベース接続情報（`DB_HOST`, `DB_PORT`, `DB_DATABASE`, `DB_USERNAME`, `DB_PASSWORD`）
    - Google Books APIキー（`GOOGLE_BOOKS_API_KEY`）※ISBN検索機能に必要

4.  **依存パッケージのインストール**
    ```bash
    composer install
    ```

5.  **アプリケーションキーの生成**
    ```bash
    php artisan key:generate
    ```

6.  **シンボリックリンクの作成**
    ```bash
    php artisan storage:link
    ```

ここまでで、マイグレーションを実行する前の環境構築が完了する。

## 3. 機能要件（追加・変更分）

| 大項目 | 機能 | 概要 |
|---|---|---|
| 書籍管理 | **書籍検索機能** | 書籍一覧ページで、キーワード（タイトル・著者）、ジャンル、並び順（新着順、評価の高い順、いいねの多い順）で書籍を検索・絞り込みできる。 |
| | **CSVエクスポート機能** | 書籍一覧ページで、表示されている検索結果をCSVファイルとしてダウンロードできる。 |
| | **ISBN検索機能** | 書籍登録ページで、13桁のISBNを入力するとGoogle Books APIを介して書籍情報を自動入力できる。 |
| マイ読書レポート | **統計情報表示** | ログインユーザーの読書活動に関する様々な統計情報を表示する。<br>・総レビュー数、総お気に入り数<br>・今月の読書数、平均評価点<br>・読書継続日数（現在/最長）<br>・評価分布（5段階評価の各件数）<br>・ジャンル別統計（レビュー数、平均評価）<br>・お気に入りジャンルTOP5<br>・高評価レビュー書籍TOP5 |
| 公開API | **書籍情報提供API** | 外部サービス向けに、認証不要で書籍情報を取得できるJSON形式のAPIを提供する。<br>・`GET /api/v1/books` (書籍一覧取得)<br>・`GET /api/v1/books/{book}` (書籍詳細取得) |

## 4. 非機能要件（追加・変更分）

| 項目 | 要件 |
|---|---|
| コーディングスタイル | ・**型宣言の徹底**: すべてのメソッドの引数、戻り値に型を明記する。<br>・**リレーションの戻り値型**: Eloquentリレーションメソッドに `HasMany`, `BelongsTo` 等の具体的な戻り値型を宣言する。<br>・**PHPDoc**: すべてのメソッドに処理内容、引数、戻り値を記述したPHPDocコメントを付与する。<br>・**Collectionメソッドの活用**: `ReportController`では、`foreach`を使わず、Collectionメソッド（`map`, `filter`, `groupBy`, `reduce`等）を駆使して宣言的なデータ処理を行う。 |
| 外部連携 | ・Google Books APIと連携し、ISBNから書籍情報を取得する。 |
| テスト | ・基本機能に加え、応用機能（検索、CSV、API、レポート）に対するFeatureテストを記述する。 |

## 5. 基本設計（追加・変更分）

### 5.1. データベース設計

基本機能編から変更なし。

### 5.2. ルーティング設計

**`routes/web.php` (追加分)**

| HTTPメソッド | URI | アクション | ルート名 | 認証 |
|---|---|---|---|---|
| GET | `/books/export/csv` | `BookController@exportCsv` | `books.export` | **必要** |
| GET | `/books/fetch` | `BookController@fetch` | `books.fetch` | **必要** |
| GET | `/reports` | `ReportController@index` | `reports.index` | **必要** |

**`routes/api.php` (新規作成)**

| HTTPメソッド | URI | アクション | ルート名 | 認証 |
|---|---|---|---|---|
| GET | `/api/v1/books` | `Api\V1\BookController@index` | (なし) | 不要 |
| GET | `/api/v1/books/{book}` | `Api\V1\BookController@show` | (なし) | 不要 |

### 5.3. コントローラ設計

| コントローラ | メソッド | 処理概要 |
|---|---|---|
| `BookController` | `index` | **(変更)** `Request`からキーワード、ジャンル、ソート順を取得し、クエリを動的に構築して検索・絞り込み・並び替えを行う。 |
| | `exportCsv` | **(追加)** `index`メソッドと同様のロジックで書籍データを取得し、`StreamedResponse`を使用してCSV形式で出力する。 |
| | `fetch` | **(追加)** `Request`からISBNを取得し、`Http`ファサードでGoogle Books APIにリクエストを送信。取得した書籍情報をJSONで返す。 |
| `ReportController` | `index` | **(追加)** ログインユーザーの書籍、レビュー、お気に入り情報を取得し、複数のプライベートメソッドを呼び出して統計データを計算。`reports.index`ビューにデータを渡す。 |
| | `(private)` | **(追加)** `generateMonthlyStats`, `generateRatingDistribution`, `generateGenreStats`など、Collectionメソッドを駆使して各種統計を計算する複数のプライベートメソッドを実装する。 |
| `Api\V1\BookController` | `index` | **(追加)** `Request`から検索クエリを取得し、書籍一覧をページネーション付きのJSONで返す。 |
| | `show` | **(追加)** 指定された書籍の詳細情報を関連データと共にJSONで返す。 |

### 5.4. バリデーション設計

基本機能編から変更なし。

### 5.5. 外部サービス連携

- **Google Books API**
  - **エンドポイント**: `https://www.googleapis.com/books/v1/volumes`
  - **リクエスト**: `q=isbn:{ISBN}` パラメータで検索
  - **認証**: APIキーを `key` パラメータで付与 (config/services.phpで管理)
  - **処理**: `BookController@fetch`内で`Illuminate\Support\Facades\Http`を使用してAPIを呼び出す。

### 5.6. Collectionメソッド活用設計 (`ReportController`)

| 統計項目 | 使用する主なCollectionメソッド |
|---|---|
| 今月の読書数 | `filter`, `count` |
| 平均評価点 | `avg` |
| 一番読んでいる著者 | `groupBy`, `map`, `sortByDesc`, `keys`, `first` |
| 評価分布 | `groupBy`, `map`, `count`, `mapWithKeys` |
| ジャンル別統計 | `flatMap`, `groupBy`, `map`, `sortByDesc`, `take` |
| お気に入りジャンル | `flatMap`, `countBy`, `sortDesc`, `take` |
| 高評価書籍 | `filter`, `sortByDesc`, `take`, `map` |
| 読書継続日数 | `map`, `unique`, `sort`, `reduce` |
