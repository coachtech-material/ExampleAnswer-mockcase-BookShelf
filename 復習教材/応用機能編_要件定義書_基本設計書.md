# 書籍レビューアプリ 要件定義書・基本設計書（応用機能編）

## 1. はじめに

### 1.1. 本書の目的

本書は、書籍レビューアプリケーションの「応用機能編」開発における要件と設計を定義するものである。基本機能編をベースに、より高度な機能と高品質なコードスタイルを導入することを目的とする。本書を読むことで、学習者は応用機能の全体像と技術的仕様を正確に把握し、手順書に従って実装を進めることができる。

### 1.2. 前提条件

- 基本機能編のすべての要件を満たしていること。
- 開発言語・フレームワークは PHP / Laravel (Laravel 10.x) を使用する。
- フロントエンドのBladeテンプレートは `coachtech-material/Preparedblade-mockcase-BookShelf` リポジトリの `advanced` ブランチで提供される。
- データベースは MySQL を使用する。
- 開発環境は Docker および Laravel Sail を使用する。

## 2. 環境構築手順

### 2.1. Laravelプロジェクトの作成 (Laravel 10.x)

以下のDockerコマンドを実行して、Laravel 10.xを明示的に指定してプロジェクトを作成します。

```bash
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    composer create-project laravel/laravel:^10.0 book-review-app
```

### 2.2. Laravel Sailのインストール

プロジェクト作成後、`book-review-app` ディレクトリに移動し、Laravel Sailをインストールします。

```bash
# プロジェクトディレクトリに移動
cd book-review-app

# Laravel Sailをインストール
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    composer require laravel/sail --dev

# Sailの設定ファイルをパブリッシュ（MySQLを選択）
docker run --rm \
    -u "$(id -u):$(id -g)" \
    -v "$(pwd):/var/www/html" \
    -w /var/www/html \
    -e COMPOSER_CACHE_DIR=/tmp/composer_cache \
    laravelsail/php82-composer:latest \
    php artisan sail:install --with=mysql
```

### 2.3. フロントエンドのセットアップ (Vite & Tailwind CSS)

1.  **NPM依存パッケージのインストール**
    ```bash
    sail npm install
    ```

2.  **Tailwind CSSのインストール**
    ```bash
    sail npm install -D tailwindcss@^3.4.0 postcss autoprefixer
    ```

3.  **設定ファイルの生成**
    ```bash
    sail npx tailwindcss init -p
    ```

4.  **Tailwind CSSのテンプレートパス設定**
    `tailwind.config.js` を開き、`content`プロパティを以下のように設定します。
    ```javascript
    /** @type {import(\'tailwindcss\

').Config} */
    export default {
      content: [
        "./resources/**/*.blade.php",
        "./resources/**/*.js",
        "./resources/**/*.vue",
      ],
      theme: {
        extend: {},
      },
      plugins: [],
    }
    ```

5.  **CSSファイルにTailwindディレクティブを追加**
    `resources/css/app.css` の中身を以下の3行に置き換えます。
    ```css
    @tailwind base;
    @tailwind components;
    @tailwind utilities;
    ```

6.  **Vite開発サーバーの起動**
    新しいターミナルを開いて実行します。このコマンドは開発中、常に実行したままにしてください。
    ```bash
    sail npm run dev
    ```

### 2.4. .env ファイルとphpMyAdminの設定

1.  **.env ファイルの確認**
    `.env` ファイルを開き、データベース接続情報が以下と一致していることを確認し、**Google Books APIキー**を追加します。
    ```ini
    DB_CONNECTION=mysql
    DB_HOST=mysql
    DB_PORT=3306
    DB_DATABASE=laravel
    DB_USERNAME=sail
    DB_PASSWORD=password

    # Google Books APIキー（自身のキーに置き換える）
    GOOGLE_BOOKS_API_KEY=Your-API-Key
    ```

2.  **phpMyAdminの追加**
    `compose.yaml` を開き、`mysql` サービスの後に以下の設定を追加します。
    ```yaml
        phpmyadmin:
            image: \'phpmyadmin:latest\'
            ports:
                - \'${FORWARD_PHPMYADMIN_PORT:-8080}:80\'
            environment:
                PMA_HOST: mysql
                PMA_USER: \'${DB_USERNAME}\n
'
                PMA_PASSWORD: \'${DB_PASSWORD}\n
'
            networks:
                - sail
            depends_on:
                - mysql
    ```

### 2.5. Sailの起動とエイリアス設定

1.  **Sailの起動**
    ```bash
    ./vendor/bin/sail up -d
    ```

2.  **エイリアス設定**
    ```bash
    echo "alias sail=\'[ -f sail ] && bash sail || bash vendor/bin/sail\'" >> ~/.zshrc
    # または bash の場合
    # echo "alias sail=\'[ -f sail ] && bash sail || bash vendor/bin/sail\'" >> ~/.bashrc
    
    # シェルを再起動
    exec $SHELL
    ```

3.  **アプリケーションキーの生成**
    ```bash
    sail artisan key:generate
    ```

## 3. 機能要件（追加・変更分）

| 大機能 | 中機能 | 機能概要 |
|---|---|---|
| **書籍管理** | **高度な検索機能** | 書籍一覧ページで、キーワード（タイトル・著者）、ジャンル、並び順（登録日、評価）を組み合わせて書籍を検索できる。 |
| | **CSVエクスポート** | 検索結果を書籍一覧ページからCSV形式でダウンロードできる。 |
| | **ISBN書籍検索** | 書籍登録ページで、ISBN（13桁）を入力してGoogle Books APIから書籍情報を自動取得・入力できる。 |
| **マイ読書レポート** | **統計表示** | ログインユーザーの読書活動に関する様々な統計情報を表示する。<br>- 総読了冊数<br>- レビュー投稿日数<br>- 読書継続日数（現在/最長）<br>- 月別統計（読了冊数/レビュー投稿数） |
| **公開API** | **書籍情報提供** | 外部アプリケーション向けに、書籍の一覧と詳細情報をJSON形式で提供する認証不要のAPI。 |

## 4. 非機能要件（追加・変更分）

| 項目 | 要件 |
|---|---|
| **コーディングスタイル** | - **型宣言の徹底**: すべてのコントローラ、モデル、FormRequest、Policyのメソッドに、引数と戻り値の型を明示的に宣言する。（例: `public function index(): View`）<br>- **リレーション戻り値型**: モデルのリレーションメソッドには、`HasMany`, `BelongsTo` などの具体的な戻り値型を宣言する。<br>- **PHPDoc**: 主要なメソッドには、処理内容、引数、戻り値を説明するPHPDocコメントを記述する。 |
| **Collectionメソッド** | - **宣言的なコード**: `foreach` などの手続き的なループを避け、`map`, `filter`, `reduce`, `groupBy` などのCollectionメソッドを積極的に活用し、宣言的で可読性の高いコードを記述する。特にマイ読書レポート機能でこれを徹底する。 |
| **外部連携** | - **HTTPクライアント**: 外部APIとの通信には、Laravel標準のHTTPクライアント (`Illuminate\Support\Facades\Http`) を使用する。 |
| **ファイルダウンロード** | - **ストリーミング**: CSVエクスポートなどの大容量ファイルを扱う可能性がある機能では、メモリ消費を抑えるため `StreamedResponse` を使用してレスポンスをストリーミングする。 |

### 5.2. コントローラ設計

| コントローラ | メソッド | 詳細仕様 |
|---|---|---|
| **BookController** | `index` | **検索機能**: `Builder::when()` を使用して、リクエストに存在するパラメータ（`keyword`, `genre_id`, `sort`）に応じて動的にクエリを構築する。<br>- `keyword`: `title` と `author` カラムに対して `LIKE`検索を行う。<br>- `genre_id`: `whereHas(\'genres\', ...)` でジャンルによる絞り込みを行う。<br>- `sort`: `orderBy()` で並び替えを行う。`rating` の場合は `withAvg` と `orderByDesc(\'reviews_avg_rating\')` を使用する。 |
| | `csvExport` | **CSVエクスポート**: `StreamedResponse` を使用する。<br>1. HTTPヘッダ（`Content-Type`, `Content-Disposition`）を設定。<br>2. `fopen(\'php://output\n

', \'w\')` で出力ストリームを開く。<br>3. `fputcsv()` でヘッダ行を書き込む。<br>4. `Book::query()->cursor()` を使用して、メモリ消費を抑えながら1件ずつ書籍データを取得し、`fputcsv()` で書き込む。 |
| | `searchByIsbn` | **ISBN検索**: `Http::get()` でGoogle Books API (`https://www.googleapis.com/books/v1/volumes`) を叩く。<br>1. `q` パラメータに `isbn:{isbn}` を指定。<br>2. `key` パラメータに `.env` から取得したAPIキーを指定。<br>3. 成功時 (`successful()` かつ `totalItems > 0`)、最初の書籍情報 (`items[0].volumeInfo`) をJSONで返す。<br>4. 失敗時は空のJSON (`{}`) を返す。 |
| **ReportController** | `index` | **マイ読書レポート**: Collectionメソッドを駆使して各種統計を算出する。<br>1. **データ取得**: `Auth::user()->reviews()->with(\'book\')->latest()->get()` でユーザーの全レビューを取得。<br>2. **総読了冊数**: `->pluck(\'book_id\')->unique()->count()` で算出。<br>3. **レビュー投稿日数**: `->pluck(\'created_at\')->map(fn ($date) => $date->format(\'Y-m-d\'))->unique()->count()` で算出。<br>4. **読書継続日数**: <br>   a. レビュー投稿日を `Y-m-d` 形式でユニークに取得し、ソートする。<br>   b. `CarbonPeriod` で最初と最後の日付から日付のシーケンスを生成。<br>   c. シーケンスをループし、レビュー投稿日が存在しない日があれば継続日数をリセット。存在すればインクリメント。この過程で現在と最長の継続日数を記録する。<br>5. **月別統計**: <br>   a. `groupBy(fn ($review) => $review->created_at->format(\'Y-m\'))` でレビューを月別にグループ化。<br>   b. `map(fn ($reviews) => [ ... ])` で各月の統計（読了冊数、レビュー数）を算出。<br>   c. `reduce( ... )` を使用して、レビューが存在しない月を0埋めする。 |
| **Api\V1\BookController** | `index` | `Book::query()` を使用し、リクエストパラメータ (`keyword`, `genre_id`) に応じて検索を行う。`paginate(20)` で結果を返す。 |
| | `show` | `load(["reviews.user", "genres"])` で関連情報をロードし、JSONで返す。 |

### 5.3. 外部サービス連携

- **サービス名**: Google Books API
- **エンドポイント**: `https://www.googleapis.com/books/v1/volumes`
- **認証**: APIキー (`.env` の `GOOGLE_BOOKS_API_KEY`)
- **リクエスト例**: `GET https://www.googleapis.com/books/v1/volumes?q=isbn:9784297124219&key=...`
- **レスポンス（主要部分）**:
  ```json
  {
    "totalItems": 1,
    "items": [

          "description": "...",
          "industryIdentifiers": [
            { "type": "ISBN_13", "identifier": "9784297124219" }
          ],
          "imageLinks": {
            "thumbnail": "..."
          }
        }
      }
    ]
  }
  ```

### 5.4. Collectionメソッド活用設計

`ReportController` の `index` メソッドは、以下のCollectionメソッドを組み合わせて実装することを必須要件とする。

| メソッド | 目的 | 使用箇所 |
|---|---|---|
| `pluck()` | 特定のキーの値のコレクションを取得する。 | 総読了冊数、レビュー投稿日数の算出 |
| `unique()` | 重複を除外する。 | 総読了冊数、レビュー投稿日数の算出 |
| `map()` | コレクションの各要素にコールバックを適用する。 | 日付フォーマットの統一、月別統計の整形 |
| `groupBy()` | 指定したキーでコレクションをグループ化する。 | 月別統計の算出 |
| `reduce()` | コレクションを単一の値に集約する。 | 月別統計の0埋め |
| `sortBy()` | コレクションをソートする。 | 読書継続日数の計算前処理 |
| `first()`, `last()` | コレクションの最初/最後の要素を取得する。 | 読書継続日数の計算（期間設定） |
